# Arquitetura de IA

## Objetivo

O Axis deve conversar naturalmente e também executar operações estruturadas.

O modelo não deve ser responsável por efeitos colaterais.

## Pipeline

```text
mensagem
  ↓
ConversationService
  ↓
AI Orchestrator
  ↓
LLM Adapter (Ollama)
  ↓
estrutura validada
  ↓
Router de intenção
  ├── conversa → resposta
  └── ação → tool/service
```

## Contexto

O contexto pode conter:

- mensagens recentes
- remetente
- grupo
- usuário da conta
- lead atualmente relacionado
- data/hora
- resumo de conversa

Não enviar histórico ilimitado.

## Saída estruturada

Exemplo conceitual:

```json
{
  "mode": "ACTION",
  "intent": "CRIAR_LEAD",
  "event": "AGENDAMENTO",
  "confidence": 0.96,
  "parameters": {
    "nome": "João",
    "dataHora": "2026-08-14T16:00:00"
  }
}
```

Para conversa:

```json
{
  "mode": "CHAT",
  "response": "Posso ajudar com leads, agenda e métricas."
}
```

## Segurança

O LLM não pode:

- executar SQL/MongoDB
- alterar documentos diretamente
- inventar execução
- acessar secrets
- escolher endpoints arbitrários

Toda ação passa por código determinístico.
