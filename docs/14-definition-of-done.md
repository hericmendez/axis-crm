# Definition of Done

Uma capability está pronta quando:

- possui contrato TypeScript;
- possui validação;
- possui service;
- possui repository/integration quando necessário;
- possui testes;
- possui tratamento de erro;
- não depende de comportamento textual frágil do LLM;
- não expõe secrets;
- possui logs úteis;
- está documentada;
- `tsc --noEmit` passa;
- testes passam.
