# Memória conversacional

A memória existe para permitir referências como:

> "Ele fechou."

quando o contexto anterior era:

> "O João marcou uma call."

## Camadas

### Short-term

Últimas mensagens da conversa.

### Summary

Resumo persistente quando o histórico ficar grande.

### CRM context

Dados reais recuperados do sistema quando necessários.

O LLM deve receber apenas o contexto necessário para a tarefa.

## Regra

Memória conversacional não substitui o banco CRM.

O CRM é a fonte da verdade sobre leads, vendas e agenda.
